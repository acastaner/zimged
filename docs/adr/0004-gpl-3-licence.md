# zimged is licensed GPL-3.0-or-later

zimged is released under GPL-3.0-or-later, so forks of this end-user app stay open, and LGPL or GPL libraries can be added later without friction. Every dependency currently chosen is permissive (MIT, Apache, BSD) and compatible with it. The rejected alternative was MIT OR Apache-2.0, the Rust convention, which allows the most reuse.

Decided in [Lock the stack](https://github.com/acastaner/zimged/issues/10).
